使い方

  1. 直す：左でページを選び、真ん中の入力欄で文・リンクを直します。右の下見に、すぐ反映されます。メニューや屋号は、左の「共通」で直します。
  2. 並びを変える・足す・消す：各ブロックの右上の「↑」「↓」「複製」「削除」を使います。新しいブロックは、いちばん下の「ブロックを追加」から入れます（えらんでいるブロックのすぐ下に入ります）。
  3. 下見：右上の「PC／スマホ」で幅を変えられます。各ブロックの「下見で見る」を押すと、下見のその部分へ移動します。下見の中のブロックを押すと、その入力欄へ移動します。下見の中のリンクは、押しても移動しません（行き先が下に出ます）。
  4. リンクの書き方：ほかのページは /contact/、ページの中の場所は /#works（「目印」の名前）、外のサイトは https://...、メールは {メール}。入力欄を押すと候補が出ます。
  5. 画像：「画像を選ぶ」でパソコンやスマホの画像を選ぶと、位置情報などを消して小さくしてから、サイトに入れます（「保存の準備」が済んでいるとき）。人の顔や、自宅・学校が分かる画像は使いません。
  6. 保存して公開する：右上のボタンを押すと、サイトに反映されます（1〜2分かかります）。はじめて使うときは、先に「保存の準備」を1回だけ行います。
  7. 途中の内容：直している途中の内容は、このブラウザの中に自動で残ります（別のパソコンやスマホには残りません）。捨てたいときは「公開中の内容に戻す」。
  8. まちがえて保存したとき：前の版は残っています。チャットで Claude に「サイトを前の版に戻したい」と伝えてください。

保存の準備（はじめの1回だけ）

このツールからサイトに保存するには、GitHub で「このサイトの中身だけを書きかえてよい」という鍵（トークン）を作り、ここに入れます。鍵は、このブラウザの中にだけ残ります。

  1. GitHub の「鍵を作る画面」を開く
    名前・持ち主・期限・権限は、はじめから入った状態で開きます。ログインを求められたら、GitHub のアカウントでログインします。
  2. さわるのは1か所だけ：「Repository access」の所で Only select repositories を選び、すぐ下に出る「Select repositories」を押して、toco-works.github.io にチェックを入れる
  3. 確かめる：「Permissions」の所に Contents があり、その右が Read and write になっている
    なっていないときは、「Add permissions」を押して Contents にチェックを入れ、右の「Access」を「Read and write」に変えます。
  4. いちばん下の緑の Generate token を押す（確認の窓が出たら、もう一度 Generate token）
  5. 出てきた github_pat_ で始まる文字の右の、コピーのボタンを押す
    この文字は、画面を閉じると二度と見られません。閉じる前に、次の手順まで進めます。
  6. このページに戻り、下の欄に貼って、「確かめて、このブラウザに覚えさせる」を押す

変えないもの：「Resource owner」は kazutech09-afk のままにします。ここを変えると、下の項目が入れかわり、toco-works.github.io を選べなくなります（変えてしまったら、手順1のボタンを押し直します）。

画面の言葉が上の説明とちがうときは、その画面のスクリーンショットを、チャットに貼ってください（鍵の文字が映っている画面は、貼らないでください）。

鍵のあつかい：鍵は、チャット・メール・ファイルに書かないでください。自分のパソコン・スマホだけで使い、人と共用のパソコンでは使いません。なくした・見られたかもしれないときは、GitHub の Settings → Developer settings → Personal access tokens で、その鍵を「Delete」します。

鍵を使わずに保存する（コピーして GitHub に貼る）

「保存して公開する」を押したときに、鍵がなければ、コピーして貼る手順が出ます。

保存のしかた（コピーして GitHub に貼る）

ボタン1つで保存したいときは、「保存の準備」を先に行ってください。

  2. GitHub の編集画面を開く
    「Page not found」と出たら、GitHub にログインしていません。右上の「Sign in」からログインして、もう一度このボタンを押します。
  3. GitHub の画面で、文字が並んでいる枠の中を1回クリック → Ctrl＋A（全部選ぶ）→ Ctrl＋V（貼りつけ）
    iPhone は、枠の中を長押し →「すべてを選択」→「ペースト」
  4. 右上の緑のボタン 「Commit changes...」 → 出てきた窓の緑の 「Commit changes」
  5. 1〜2分待って、サイトを開いて確かめる
コピーできないとき（中身を手で選んでコピーする）

ページを追加

作ったページは、1〜2分で開けるようになります。メニューやボタンからのリンクは、自動では付きません。「共通」のメニューや、ボタンのリンクに足してください。
